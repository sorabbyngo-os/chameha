# Execution Engine

> The Execution Engine converts approved decisions into real-world actions.

---

# Purpose

The Execution Engine is responsible for acting.

It interfaces with external systems to perform approved operations.

Execution is the final stage of the Twin lifecycle.

---

# Vision

Safely execute actions while maintaining complete auditability.

---

# Responsibilities

The Execution Engine

- Execute approved tasks
- Coordinate external systems
- Monitor execution
- Retry recoverable failures
- Report progress
- Verify completion
- Roll back when possible
