# Memory Engine

> The Memory Engine stores everything the Twin has experienced.

---

# Purpose

Memory is the persistent record of observation.

It transforms temporary events into long-term experience.

Without memory, the Twin resets after every interaction.

---

# Vision

Remember everything that matters.

Forget what is unnecessary.

Strengthen important memories.

Compress redundant experiences.

---

# Responsibilities

The Memory Engine

- Stores observations
- Retrieves memories
- Indexes experiences
- Compresses redundant memories
- Associates related memories
- Maintains temporal history

---

# Memory Types

## Episodic

Experiences.

Examples

- Meetings
- Conversations
- Events

---

## Semantic

Facts.

Examples

- Favourite food
- Job title
- Company revenue

---

## Procedural

Skills.

Examples

- Workflows
- Operating procedures
- Manufacturing processes

---

## Emotional

Importance.

Examples

- Positive experiences
- Negative experiences
- High-impact events

---

# Inputs

Receives observations.

```
Observation
        ↓
```

# Outputs

Provides memories to

Memory only records.

Reasoning belongs elsewhere.
