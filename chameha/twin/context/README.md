# Context Engine

> The Context Engine determines what matters right now.

---

# Purpose

Reality contains enormous amounts of information.

The Twin cannot reason over everything simultaneously.

The Context Engine selects the subset of information that is currently relevant.

It transforms the complete Twin into the Active Twin.

---

# Vision

Provide every downstream engine with exactly the information it needs at the moment it needs it.

Context is dynamic.

It changes continuously as situations evolve.

---

# Responsibilities

The Context Engine

- Retrieves relevant memories
- Retrieves relevant knowledge
- Retrieves relevant model state
- Prioritizes information
- Removes irrelevant information
- Builds temporary working context

---

# Sources

Context is assembled from

- Observation
- Memory

# Working Memory

The Context Engine creates a temporary working memory.

Working memory exists only while reasoning is taking place.

It is rebuilt continuously.
