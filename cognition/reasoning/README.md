# Reasoning Engine

> *The inference and logical thinking engine of Chameha.*

---

# Overview

The Reasoning Engine transforms information into understanding.

It combines observations, memory, knowledge, beliefs, goals, and context to determine what is most likely true and what should happen next.

Unlike an LLM, reasoning is independent of language generation.

Language is only one way reasoning expresses itself.

---

# Purpose

Reasoning exists to answer questions such as

- What is happening?
- Why is it happening?
- What does this imply?
- What should be considered?
- What are the possible outcomes?
- Which option is most rational?
