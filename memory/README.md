# Chameha Memory System

The Memory System is the persistent cognitive substrate of Chameha.

Unlike conventional AI assistants, Chameha separates memory into multiple cognitive systems modeled after human cognition.

---

## Architecture

```
Memory Manager
        │
        ├──────────────┐
        │              │
        ▼              ▼

 Working        Consolidation

        │              │

        ▼              ▼

 Episodic      Semantic

        │              │

        └──────┬───────┘

               ▼

       Procedural

               │

               ▼

    Autobiographical

               │

               ▼

           Storage
```

---

## Memory Types

### Working Memory

Current reasoning context.

Short-lived.

Fast.

---

### Episodic Memory

Experiences.

Conversations.

Events.

Chronological history.

---

### Semantic Memory

Facts.

Concepts.

Knowledge.

Relationships.

---

### Procedural Memory

Skills.

Execution procedures.

Learned workflows.

---

### Autobiographical Memory

Chameha's understanding of

- itself

- the user

- long-term relationship

- long-term goals

---

### Sensory Memory

Temporary perception.

Images.

Audio.

Touch.

Vision.

---

### Consolidation

Moves information between memory systems.

---

### Retrieval

Searches every memory system.

---

### Storage

Persists all memories.

Supports multiple storage providers.

---

## Design Goals

Memory should be

- persistent

- contextual

- explainable

- searchable

- secure

- offline capable

- distributed
